# Leonardo PC port status

A one-page status board for Leonardo, the community project getting the console version of the game running on PC: how far it gets, on which PCs, and what changed lately.

Live at https://leonardo-status.pages.dev (this repo's GitHub Pages copy, https://eirik200.github.io/leonardo-status/, is a mirror).

Three pages: the status board (`index.html`, data built in), a gallery of screenshots (`gallery.html`, pictures in `gallery/` with their metadata removed) and the contributors (`contributors.html`, GitHub usernames and change counts only). Both are rebuilt by hand from the project's pull requests and work list. Not made by or connected to Rockstar Games.
