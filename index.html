          How this port is built

          The console uses the same kind of processor as a PC, so the game's own code runs directly on yours, with no emulator in between. What Leonardo rebuilds is everything around that code:

          More about how it works

          Everything around the game's code has to be rebuilt for PC first, which is why early progress takes longer.

          The official version has to keep working on many different PCs, so every change is reviewed before it is accepted. That is why some fixes wait for a while before they are added.

          Small exceptions: a few pieces are still imitated where PC parts differ from the console. Intel processors and older AMD processors imitate a handful of console-only processor instructions, and NVIDIA, Intel and Apple graphics cards imitate a way of grouping graphics work that AMD cards, like the console's, handle directly.
